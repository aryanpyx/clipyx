# Graphizo chart kit

This folder lets an AI agent make animated chart presets for **Graphizo**, a chart node for DaVinci Resolve (Fusion page).

When the user asks for a Graphizo chart, graph, data animation, chart look or changes to one, **read `SKILL.md` and follow it**. It points you to `Graphizo AI Guide.md`, the full reference.

Ground rules:

- Ask the user where to save presets before writing anywhere outside this folder.
- Put new work in `my-presets/`. Leave the kit files unchanged unless the user asks: `presets/`, `specs/`, `reference/`, `tools/`, the guide, `SKILL.md`.
- Use the user's numbers exactly; never present invented data as real.
- Do not delete or overwrite the user's files without asking.
