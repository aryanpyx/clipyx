# Clipyx DaVinci Resolve Library Catalog

The Clipyx Library contains 319 curated code snippets, expressions, node trees, and Lua scripts for DaVinci Resolve Studio and Fusion.

## Breakdown by Item Type
- **Expressions (76 items):** Single-line and multi-line procedural Lua expressions for Text+ `Styled Text`, Transform, Merge, and modifiers.
- **Motion Graphics (197 items):** Standalone composite animations, countdowns, glitch effects, neon rings, and overlay elements.
- **Node Trees (34 items):** Multi-node Fusion compositions ready to paste directly into the Fusion node editor.
- **Lua Scripts (9 items):** Automation scripts executed via Resolve's Fusion Script console.
- **AI Integrations (3 items):** Direct agentic integration recipes.

## Major Categories
1. **Text & Typography:** Countdowns, counters, typewriter effects, character staggering, dynamic labels.
2. **Titles & Lower Thirds:** Minimalist split reveals, broadcast banners, cyber cybernetic boxes.
3. **Backgrounds & Overlays:** Matrix meshes, particles, floating dust, gradient sweeps, scanlines.
4. **Looks & Grading:** VHS tape distortion, CRT monitors, chromatic aberration, film halation, anamorphic streaks.
5. **Loaders & Progress:** Circular spinners, loading bars, radial percentages, buffering animations.
6. **Interface & HUD:** Crosshairs, biometric readouts, waveform meters, circuit lines, coordinate trackers.
7. **Social & CTA:** Subscribe notifications, like buttons, follower counter tickers.

## How to Apply in DaVinci Resolve
- **Expressions:** Right-click the input field in Fusion Inspector -> select **Expression** -> paste the expression code.
- **Node Trees:** Click anywhere inside the Fusion Node Editor -> press `Ctrl+V` (or `Cmd+V`).
- **Modifiers:** Right-click a slider or parameter -> select **Modify With** -> pick the modifier specified in the library item.
