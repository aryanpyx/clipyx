Frequently asked questions

Common questions about Clipyx tools and installs.

What if I need technical support?

If a tool is throwing an error or you need help, jump into our Discord community or use the contact form below. We will always help you get it working.

What software do Clipyx tools support?

Clipyx tools are built for DaVinci Resolve, Fusion, and AI workflows. Each product page lists exactly which software it supports.

Are Clipyx plugins free?

Yes. Every Clipyx plugin, Fuse, macro and OpenFX tool for DaVinci Resolve and Fusion is free to download and to use in your own projects, client work included, and so are its updates. Sharing or reselling the files themselves is not allowed: see the license.

Can I use these tools on multiple computers?

Yes. You can install Clipyx tools on any computer you own. Tools that need activation, such as AnimizoFX, use the free license key from your download email, and one key covers up to 3 computers. To move a key to another computer, contact us and we'll move it for you.
