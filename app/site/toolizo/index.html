Overview

Toolizo opens as a window inside DaVinci Resolve. Your library is a folder on your disk: drop files in, sort them into folders, star your favorites and put everything in your own order.

Drag a tile onto the timeline or the Fusion page. Nodes you select on the Fusion page become a reusable effect with one click.

Install as turns an effect into a title, a generator or an effect in Resolve's own Effects library, so it is there in every project. That goes for your own effects and for the motion graphics you import from the Clipyx Library.

The Clipyx Library is built in: the expressions, motion graphics, node trees and scripts from clipyx.com, with previews, ready to import. Link Toolizo once to a free Clipyx account to use it.

Setup & help guide for Toolizo Install, find it in Resolve, the controls, common problems, uninstall

Toolizo v1.5, the media library plugin: Windows 10 or 11, 64-bit; macOS 12 or later on Apple silicon or Intel (Resolve 21.1 itself needs macOS 15 on Apple silicon). DaVinci Resolve 21 or newer.

Install
  1. Extract the complete ZIP first, and read legal/CLIPIZO_PRODUCT_LICENSE.txt.
  2. Save your project and quit DaVinci Resolve.
  3. Windows: run Toolizo-v1.5-Setup.exe and allow the administrator prompt. If “Windows protected your PC” appears, choose More info, then Run anyway. The installer isn't signed.
  4. macOS: open Toolizo-v1.5.pkg and enter your Mac's administrator password. If macOS won't open it, right-click it, choose Open, then Open again. If it is still blocked, open System Settings → Privacy & Security and choose Open Anyway. The package isn't notarized by Apple.
  5. The plugin goes where Resolve looks for OpenFX plugins, and Toolizo gets an entry in Resolve's Scripts menu.
  6. Start DaVinci Resolve.
Where it appears in Resolve

Workspace > Scripts > Clipyx > Toolizo opens the window.

Or add the Toolizo effect to a clip (Effects > OpenFX > Clipyx > Toolizo) and click Open Toolizo in the Inspector.

Your library is a folder, Clipyx > Toolizo > Library in your Documents, made the first time. To keep it somewhere else, right-click Library in the sidebar and choose Change Library Folder.

Controls in plain words

Some controls appear only after choosing the relevant mode.

Library
Import media
Drop files or folders onto the window, or right-click empty space in the grid and choose Import Media. Toolizo copies them into the library, each kind in its own folder.
Search and sort
Search looks through the whole library. The sort button orders it: your own order, by name, by recently added or by type.
Favorites
Star a tile to add it to Favorites, which keep their own order.
Folders and separators
Make, rename, nest and reorder folders in the sidebar. Drag tiles into your own order and add colored separators.
Delete
Moves the item to the Recycle Bin or the Trash, after asking.
Using items
Drag
Drag a tile onto Resolve's timeline or the Fusion page.
Add nodes
Double-click an effect to add its nodes on the Fusion page, connected. The bar's settings can make it one click.
Capture
Turns the nodes selected on the Fusion page into an effect. You can also copy nodes and paste them into Toolizo.
Install as
Right-click an effect and open Install as to put it into Resolve's own Effects library as a title, a generator or an effect; the kind it is installed as is ticked. It shows under Toolbox > Titles, Generators or Effects on the Edit page right away when you opened Toolizo from Workspace > Scripts > Clipyx > Toolizo; if Resolve doesn't list it, start Resolve again. Type a title's or generator's text in the Inspector. Remove from Edit Page takes it out again.
Add to Timeline
Right-click a title or generator and choose Add to Timeline (in orange): it goes onto the timeline you have open, at the playhead. Open Toolizo from Workspace > Scripts > Clipyx > Toolizo first.
Edit Effect
Changes an effect's name, icon and code.
Manage Presets
In the menu: a list of everything Toolizo added to Resolve's Edit page. Click one to take it off, or Remove All.
Fusion Mode
Shows Toolizo as a slim bar over Resolve, horizontal or vertical.
Brands
New brand
Makes a folder for a brand in the sidebar, for its media, effects and color palettes.
Palettes
Click a swatch to copy its hex. Pick colors in the color picker or type them as hex or rgb().
Clipyx Library and My items
Connect
Links Toolizo to a free Clipyx account in your browser, once.
Clipyx Library
Expressions, motion graphics, node trees and scripts from clipyx.com. Double-click or drag an item to import it. An imported motion graphic can then go to the Edit page as a title with Install as.
My items
Your own items in your Clipyx account, on any computer. Save an effect, an expression or a script. Items are private unless you show them on your profile.
Common problems
Windows says it protected your PC
Click More info, then Run anyway. The installer isn't signed.
Windows blocks the installer (error 4551)
Toolizo isn't code-signed yet, and Windows 11's Smart App Control blocks apps that aren't. Toolizo installs and loads only on a PC where Smart App Control is off (Windows Security > App & browser control). Turning it off lowers Windows' protection, and some Windows versions can't turn it back on without a reset, so check that before you decide.
A Mac won't open the package
Right-click it, choose Open, then Open again. If macOS still blocks it, use System Settings > Privacy & Security > Open Anyway.
Toolizo is missing from the Scripts menu or the effects
Run the installer again while Resolve is closed, then start Resolve.
Capture or adding nodes does nothing
Open Toolizo from Workspace > Scripts > Clipyx > Toolizo; a window opened from the Inspector can't do either.
The Clipyx Library asks to connect
Click Connect and link Toolizo to your free Clipyx account in the browser. The page shows the same code as Toolizo.
Uninstall
  1. Close Resolve. Windows: Settings > Apps > Installed apps > Toolizo > Uninstall. macOS: quit Resolve, then move Toolizo.ofx.bundle in /Library/OFX/Plugins and Toolizo.lua in ~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/Clipyx (only that file: the other Clipyx tools there stay) to the Trash.
  2. Your library and settings stay.

Still stuck? Contact Clipyx with the plugin version, Resolve version, operating system and the exact error message.
